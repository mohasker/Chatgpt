# نظام فواتير الحرم

نظام فواتير ومستندات لشركة الحرم للصيانة والزراعة ذ.م.م. يحل محل ملف Excel السنوي.

## ماذا يفعل (الإصدار 2)
- **دخول وصلاحيات**:
  - **الإدارة (admin / CEO)**: كل الشاشات.
  - **المحاسب**: الفواتير والطباعة والدفعات والعملاء فقط، بدون لوحة التحكم والإجماليات.
  - كلمات المرور مشفرة (PBKDF2).
- **ترقيم تسلسلي مستمر** لكل نوع مستند: `ALH-INV-001001` و `PRO` و `CON` و `WCC` و `WRN` و `CVL` و `RCV`.
  - الرقم يُحجز عند الاعتماد فقط.
  - لا يتكرر ولا يُعاد استخدامه.
  - تقرير لفحص التسلسل.
- **قفل الفاتورة بعد الاعتماد**:
  - نسخة ثابتة من بيانات الشركة والعميل.
  - الإلغاء بسبب مكتوب، مع ختم CANCELLED.
  - المسودات تحمل علامة DRAFT.
- **المستندات**: الفاتورة (مطابقة للنموذج الأصلي)، شهادة الإنجاز، شهادة الضمان (ثلاثة نماذج حسب نوع العمل مع تاريخ الانتهاء)، كتاب التغطية (مفصل أو مختصر، عربي أو إنجليزي)، سند القبض.
- **الختم والتوقيع**: خيار لكل فاتورة، ويمكن تغييره عند الطباعة.
- **الفاتورة المجمعة / المخصصة**:
  - تُنشأ من فواتير قائمة أو ببنود حرة.
  - تحمل الغرض وحالة التحويل.
  - توزَّع الدفعة على الفواتير الأصلية.
  - خارج الحسابات العامة.
- **الدفعات**: سند قبض لكل دفعة، عكس الدفعة بسبب مكتوب، ورفض الدفعة الزائدة عن الرصيد.
- **الفواتير المستوردة من Excel**: تبقى خارج مؤشرات التحصيل حتى يراجعها مستخدم الإدارة، فرادى أو جماعياً.
- **لوحة الإدارة**: مقارنة بالسنة السابقة، التحصيل، الرصيد المفتوح، المسودات، المجمعة، المبدئية، التوزيع حسب نوع الأعمال والعميل والموقع.
- **التقارير**: سجل الفواتير، الملخص المجمّع، الأرصدة المفتوحة، المقبوضات، سجل المجمعة، كشف حساب العميل. التصدير إلى Excel أو PDF.
- **سجل المستندات** لكل مستند صادر، و**سجل تدقيق** لكل عملية باسم المستخدم.

## أول تشغيل
1. يفتح مالك النظام الصفحة، فتظهر شاشة التهيئة.
2. ينشئ حساب الإدارة (`admin`)، وحساب المحاسب (`accountant`) اختيارياً.
3. يشارك الصفحة من claude.ai: الإدارة بصلاحية **محرر**، والمحاسب بصلاحية **مساهم**.

## التشغيل
- **النسخة السحابية** (الأساسية): صفحة Claude Artifact مع قاعدة بيانات مشتركة. تعمل من أي جهاز، وتُشارك مع الموظفين من قائمة Share. الطباعة تتم بتنزيل ملف PDF ثم طباعته.
- **النسخة المستقلة**: الملف `dist/index.html` يعمل على أي استضافة ويب أو من الجهاز مباشرة، مع طباعة مباشرة. البيانات في هذه النسخة تُحفظ في المتصفح فقط، فخذ نسخة احتياطية دورياً.

## الملفات
| الملف | الغرض |
|---|---|
| `src/app.html` | الكود المصدري للتطبيق |
| `assets/*.b64` | الشعار، تذييل الاتصال، التوقيع، الختم |
| `build.py` | يبني `dist/artifact.html` و `dist/index.html` |
| `tools/extract_excel.py` | يستخرج الفواتير والعملاء من ملف Excel القديم |
| `tools/seed_from_extract.py` | يحوّل المستخرَج إلى سجلات لقاعدة البيانات |

```bash
python3 build.py
```

```bash
python3 tools/extract_excel.py "Alharam Invoice 2026.xlsm" seed.json
```

```bash
python3 tools/seed_from_extract.py seed.json seed_out
```
