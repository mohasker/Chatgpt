# نظام فواتير الحرم

نظام فواتير ومستندات لشركة الحرم للصيانة والزراعة ذ.م.م. يحل محل ملف Excel السنوي.

## ماذا يفعل
- **الفواتير**: إدخال الفاتورة مرة واحدة وحفظها في قاعدة بيانات، وإعادة طباعتها في أي وقت.
  - الترقيم يتبع نمط الملف القديم: `ALH-سنة-شهر+تسلسل`، مثل `ALH-26-1101`.
  - تدعم البنود ذات المبلغ المقطوع، وعناوين الأقسام، والخصم.
  - تدعم الاستقطاعات: المحتجزات (مثلاً 5%)، والدفعات المقدمة، وفواتير نسبة الإنجاز.
- **أنواع مستقلة**:
  - **الفاتورة المبدئية** (`PF-26-001`): يمكن تحويلها إلى فاتورة رسمية.
  - **الفاتورة المجمعة / المخصصة** (`SP-26-001`): لها تسلسل خاص، ولا تدخل في الإيرادات ولا التحصيل ولا أعمار الديون. تُربط بالفواتير الأصلية، وتحويل العميل يمكن توزيعه دفعاتٍ على تلك الفواتير.
- **المستندات لكل فاتورة** (من نماذج ثابتة):
  - الفاتورة.
  - شهادة إنجاز الأعمال (Completion Certificate).
  - شهادة ضمان الأعمال (Warranty Certificate).
  - كتاب التغطية بالعربي أو الإنجليزي.
  - ملف PDF واحد يجمع المستندات الأربعة.
- **الدفعات والحالة**: الحالة تُحسب تلقائياً (غير مدفوعة، جزئية، مدفوعة، متأخرة، ملغاة)، ويمكن تسجيل الدفع لعدة فواتير دفعة واحدة.
- **لوحة التحكم**:
  - إجمالي الفواتير والمحصّل والمستحق والمتأخرات.
  - رسم شهري.
  - أعمار الديون.
  - أكبر العملاء.
- **التقارير** (تُصدَّر إلى Excel أو PDF):
  - سجل الفواتير.
  - ملخص مجمّع حسب الشهر أو العميل أو الموقع أو نوع الأعمال.
  - أعمار الديون.
  - المقبوضات.
  - سجل الفواتير المجمعة.
  - كشف حساب لكل عميل.
- **الإعدادات**:
  - بيانات الشركة والبنك.
  - إظهار الختم والتوقيع أو إخفاؤهما.
  - تعديل نصوص الشهادات وكتاب التغطية.
  - نسخ احتياطي واستعادة بصيغة JSON.
  - تصدير كامل إلى Excel.

## التشغيل
- **النسخة السحابية** (الأساسية): صفحة Claude Artifact مع قاعدة بيانات مشتركة. تعمل من أي جهاز، وتُشارك مع الموظفين من قائمة Share. الطباعة تتم بتنزيل ملف PDF ثم طباعته.
- **النسخة المستقلة**: الملف `dist/index.html` يعمل على أي استضافة ويب أو من الجهاز مباشرة، مع طباعة مباشرة. البيانات في هذه النسخة تُحفظ في المتصفح فقط، فخذ نسخة احتياطية دورياً.

## الملفات
| الملف | الغرض |
|---|---|
| `src/app.html` | الكود المصدري للتطبيق |
| `assets/*.b64` | الشعار، تذييل الاتصال، التوقيع، الختم |
| `build.py` | يبني `dist/artifact.html` و `dist/index.html` |
| `tools/extract_excel.py` | يستخرج الفواتير والعملاء من ملف Excel القديم |
| `tools/seed_from_extract.py` | يحوّل المستخرَج إلى سجلات لقاعدة البيانات |

```bash
python3 build.py
```

```bash
python3 tools/extract_excel.py "Alharam Invoice 2026.xlsm" seed.json
```

```bash
python3 tools/seed_from_extract.py seed.json seed_out
```
